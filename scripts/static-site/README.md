# Статическая демо-копия сайта (GitHub Pages)

Папка `docs/` в корне репозитория — готовая статическая копия сайта с демо-данными: все
страницы, картинки, стили и шрифты, без сервера и базы. Её публикует GitHub Pages.

## Как опубликовать

Settings → Pages → Build and deployment → **Deploy from a branch**, ветка `main`:

- папка **`/docs`** — сайт откроется по адресу `https://<user>.github.io/<repo>/`;
- или папка **`/ (root)`** — корневой `index.html` сам перенаправит в `docs/`.

Все ссылки в копии относительные, поэтому она работает и на `github.io`, и на своём домене,
и просто открытой из папки на компьютере.

## Что работает без сервера

- все страницы: главная, поиск, каталог производителей, карточки позиций и компаний, рынок
  заказов, тарифы, кабинет демо-предприятия (гостевой вход);
- поиск по сохранённым запросам (подшипник, фильтр, гидроцилиндр, амилаза и другие, см.
  `SEARCH_QUERIES` в `build.mjs`); строка поиска подбирает ближайший сохранённый запрос;
- меню на телефоне, панель «+» в строке поиска, переключение фото в галерее;
- кнопки «Войти» и «Войти как гость» ведут в демо-кабинет.

Отправка форм, оплата, загрузка файлов и поиск по фото требуют сервера: в копии они
показывают подсказку «Это демо-версия».

## Как пересобрать

```bash
npm run db:start && npm run db:deploy && npm run db:seed   # демо-база
npm run build && npx next start -p 3000                     # приложение
node scripts/static-site/build.mjs docs                     # в другом терминале
```

Скрипт обходит все ссылки, начиная с главной и списка поисковых запросов, сохраняет готовый
HTML без скриптов Next.js и подключает `static-demo.js` с демо-поведением.
